INDUVO E.C.A. — статичний лендинг
1. Розпакуйте ZIP. Завантажте папку з index.html на Netlify Drop.
2. У налаштуваннях Netlify увімкніть Forms / Form detection, за необхідності виконайте повторний deploy. Перевірте тестову заявку та налаштуйте сповіщення.
3. Тексти редагуються в index.html, оформлення — style.css.
4. Фото моделей використовують прямі посилання на офіційний сайт E.C.A. Локальне завантаження було недоступне. При відмові зовнішнього сервера Proteus має резервне фото з КП, Confeo — підписану схему. Для незалежності від сервера замініть URL у чотирьох тегах img на локальні офіційні фотографії.
5. Перед публікацією перевірте наявність, гарантійні умови, комплектацію конкретних артикулів та відповідність кольору Confeo партії.
